# Репетитор английского — демонстрационный сайт

Одностраничный сайт на HTML5, CSS3 и JavaScript с ES-модулями.
Без фреймворков, сборки, внешних библиотек, CDN и загрузки шрифтов.
Все данные вымышлены. Форма имитирует отправку и не сохраняет данные.

По согласованию используется существующий публичный репозиторий
`mansiks1/tutor-landing-demo`. Прежняя история сохранена, к ней добавлены
семь отдельных коммитов. GitHub Pages подключается только после
явного подтверждения владельца: «публикуем».

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Пустой семантический каркас и подключения файлов |
| `content.js` | Всё содержимое: тексты, цены, отзывы, контакты и подписи |
| `script.js` | Отрисовка, проверка формы и мобильное меню |
| `styles.css` | Оформление и адаптивная вёрстка |
| `.gitignore` | Исключения для Git |

## Как посмотреть сайт на компьютере и телефоне

ES-модули требуют HTTP-сервера. Двойной щелчок по `index.html`
через `file://` не запустит сайт: браузер ограничивает загрузку модулей.
Это описано в [руководстве MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules).

Откройте PowerShell в папке проекта. Если установлен Python 3:

```powershell
py -m http.server 4173 --bind 0.0.0.0
```

Если Python отсутствует, используйте установленный Node.js. Скопируйте
весь следующий блок в PowerShell; дополнительные пакеты не нужны:

```powershell
@'
const http = require('node:http');
const fs = require('node:fs');
const path = require('node:path');
const types = {'.html':'text/html; charset=utf-8','.js':'text/javascript; charset=utf-8','.css':'text/css; charset=utf-8','.jpg':'image/jpeg','.jpeg':'image/jpeg','.png':'image/png','.webp':'image/webp','.svg':'image/svg+xml'};
const files = new Set(['index.html','content.js','script.js','styles.css']);
http.createServer((req,res) => {
  const name = new URL(req.url,'http://localhost').pathname.slice(1) || 'index.html';
  const photo = /^images\/[a-zA-Z0-9_.-]+\.(png|jpe?g|webp|svg)$/i.test(name);
  if (!files.has(name) && !photo) { res.writeHead(404); res.end(); return; }
  fs.readFile(path.join(process.cwd(),name),(error,data) => {
    if (error) { res.writeHead(404); res.end(); return; }
    res.writeHead(200,{'Content-Type':types[path.extname(name).toLowerCase()],'Cache-Control':'no-store'});
    res.end(data);
  });
}).listen(4173,'0.0.0.0',() => console.log('http://127.0.0.1:4173'));
'@ | node
```

На компьютере откройте `http://127.0.0.1:4173/index.html`.
Для телефона подключите оба устройства к одной домашней Wi-Fi-сети,
найдите IPv4-адрес компьютера командой `ipconfig` и откройте
`http://АДРЕС-КОМПЬЮТЕРА:4173/index.html` в браузере телефона.
Например, для адреса `192.168.1.10`: `http://192.168.1.10:4173/index.html`.
На телефоне `localhost` означает сам телефон, а не компьютер.
Для подключения с телефона может потребоваться разрешить серверу
входящие подключения в брандмауэре для частной сети.
Завершение сервера — `Ctrl+C` в его терминале.

## Как поменять содержимое

Откройте **`content.js`** в обычном редакторе текста, например VS Code.
Меняйте значения справа от двоеточия; названия полей слева сохраняйте.
Текст находится между кавычками, цены и длительность — числа без кавычек.
После строки или объекта сохраняйте запятую. Чтобы вставить кавычки
в текст, удобнее использовать «ёлочки». `\n` внутри строки означает перенос.
Сохраните файл в UTF-8 и обновите страницу браузера.

| Что изменить | Где искать в `content.js` |
| --- | --- |
| Имя и подпись в шапке | `brand.name`, `brand.slogan` |
| Букву на значке | `brand.monogram` |
| Заголовок, описание и кнопку первого экрана | `hero.title`, `hero.subtitle`, `hero.buttonText` |
| Остальные надписи первого экрана | Другие поля `hero` |
| Рассказ о преподавателе | `about.name`, `about.text`, `about.details`, `about.facts` |
| Заголовок раздела о преподавателе | `about.heading`, `about.eyebrow` |
| Фото и подпись | `about.photo`, `about.photoAlt`, `about.photoCaption` |
| Названия, описания и цены программ | Список `subjects` |
| Отзывы | Список `reviews` |
| Телефон, Telegram, почту | `contacts.phone`, `contacts.telegram`, `contacts.email` |
| Варианты в выпадающем списке | `formSubjects` |
| Примечание в подвале | `footerNote` |
| Меню, названия разделов, подписи полей, ошибки | `ui` |
| Название вкладки и описание страницы | `ui.pageTitle`, `ui.description` |

### Цены и программы

В `subjects` каждый блок в фигурных скобках — одна карточка:

```javascript
{
  name: "Английский для себя",
  description: "Разговорная практика и понятная грамматика.",
  price: 1600,
  duration: 60,
  tag: "От первых слов к диалогу",
},
```

`name` — название, `description` — описание, `price` — цена в рублях,
`duration` — длительность в минутах, `tag` — короткая подпись.
Для новой карточки скопируйте целый блок внутри списка `subjects`.
Добавьте такое же название в `formSubjects`, чтобы кнопка карточки
автоматически выбирала его в форме. Порядок блоков задаёт порядок карточек.

### Отзывы

В `reviews` копируйте или удаляйте целый блок:

```javascript
{
  name: "Мария",
  text: "Мне стало проще говорить по-английски.",
  rating: 5,
  detail: "Английский для путешествий",
},
```

`name` — имя, `text` — отзыв, `rating` — целая оценка от 1 до 5,
`detail` — подпись под именем. Демонстрационные отзывы обозначены как вымышленные.

### Контакты и фото

Телефон указывайте с кодом страны, Telegram — в виде `@username`,
email — обычным адресом. Ссылки создаются автоматически.
Демонстрационные контакты не предназначены для реальной связи.

Для фото создайте папку `images`, положите туда `anna.jpg` и измените:

```javascript
photo: "images/anna.jpg",
photoAlt: "Портрет преподавателя Анны Мироновой",
photoCaption: "Анна Миронова, преподаватель английского",
```

При `photo: ""` выводится серый блок с надписью из `about.photoLabel`.
Используйте в имени файла латиницу без пробелов. Добавьте фото в коммит.

### Оформление

Цвета, шрифты, размеры и отступы собраны в `:root` файла `styles.css`.
Например, `--accent` — цвет кнопок, `--paper` — фон, `--gutter` — боковой
отступ (16 px). Пороги адаптивности 64rem и 52rem находятся в `@media`:
CSS-переменные нельзя использовать в условиях медиазапросов.

### Как сохранить и опубликовать изменения

Одна самостоятельная правка — один коммит. Например, после изменения цены:

```powershell
git add content.js
git commit -m "Обновлена цена занятия"
git push origin main
```

Для фото добавьте `git add images/anna.jpg content.js` перед коммитом.
Для изменения оформления — `git add styles.css`.
До подключения Pages `git push` обновляет только код в репозитории.
После подключения Pages изменения в `main` запускают обновление сайта.

## Как опубликовать на GitHub Pages

Публиковать только после явного «публикуем» от владельца.
Текущий репозиторий уже публичный: менять его видимость не требуется.
Убедитесь, что последние изменения отправлены в `main`:

```powershell
git push -u origin main
gh api -X POST repos/mansiks1/tutor-landing-demo/pages -f "source[branch]=main" -f "source[path]=/"
```

Команда `POST` предназначена для первого включения Pages. Если Pages уже
подключён, повторно создавать его не нужно: достаточно `git push`.
Альтернатива через интерфейс GitHub: Settings → Pages → Deploy from a branch
→ ветка `main`, папка `/(root)` → Save.

Адрес после публикации: https://mansiks1.github.io/tutor-landing-demo/.
Обычно развёртывание занимает 1–2 минуты, иногда дольше.
Проверить состояние можно командой:

```powershell
gh api repos/mansiks1/tutor-landing-demo/pages
```

Источник публикации описан в [документации GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
Здесь используются относительные пути `./`, поэтому сайт подходит
для размещения в подпапке репозитория на GitHub Pages.

## Как подключить отправку формы

Сейчас `sendBooking(data)` в `script.js` лишь ждёт 450 мс. Сообщение
«Спасибо! Я свяжусь с вами» показывает завершение демонстрации,
а не реальную доставку заявки. Данные не попадают в сеть, хранилище или консоль.

Форма передаёт в эту функцию объект из четырёх строк:

```javascript
{
  name: "Имя ученика",
  contact: "@username",
  subject: "Английский для себя",
  time: "Будни после 19:00, Москва"
}
```

**Вариант с Google Forms.** Создайте форму с этими четырьмя вопросами.
Самый простой путь — заменить демонстрационную форму встроенной Google Form
или ссылкой на неё: доставку и подтверждение обработает Google.
Если нужно сохранить текущий дизайн, подключите собственный серверный
обработчик или Google Apps Script с проверкой результата и настройкой CORS.
Поля исходной Google Form и их идентификаторы зависят от созданной формы.
Не используйте `fetch` с `mode: "no-cors"` для вывода подтверждения доставки:
непрозрачный ответ не позволяет убедиться, что заявка принята.

**Вариант с Telegram-ботом.** Разместите отдельный серверный обработчик,
который принимает четыре поля, проверяет их, ограничивает частоту запросов
и отправляет сообщение через Bot API. Токен бота и `chat_id` храните на
сервере в переменных окружения. Не добавляйте секреты в `content.js`,
`script.js` или Git. GitHub Pages размещает статические файлы и не исполняет
серверный обработчик. Для него нужен отдельный хостинг и разрешённый CORS
для адреса сайта.

Замените тело `sendBooking` запросом к своему обработчику. Показывайте успех
только после подтверждённого ответа; при ошибке выбрасывайте исключение —
`handleBooking` уже сохраняет введённые поля и показывает сообщение об ошибке.
Повторите валидацию на сервере. После подключения замените демонстрационные
надписи `ui.booking.demoNote` и `ui.booking.successNote` в `content.js`.
При необходимости пустая строка отключает дополнительный текст успеха.

## Проверка перед публикацией

- Просмотрите страницу на телефоне и компьютере, проверьте меню и якоря.
- Отправьте пустую форму: должны появиться четыре ошибки.
- Проверьте неверный контакт, затем телефон или `@username`.
- Проверьте выбор направления из карточки и успешную демонстрацию отправки.
- После добавления реальной отправки проверьте получение заявки и обработку ошибок.
- Убедитесь, что вымышленные сведения заменены, если сайт перестал быть демо.
